## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hackwithim/Forgex.git
   cd Forgex
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the local development server:**
   ```bash
   npm run dev
   ```
4. **Open in your browser:**
   ```
   http://localhost:8080/ (or http://localhost:3000/)
   ```
